# 🎯 AI Career Coach

AI-powered career preparation platform designed to help students improve their resumes and prepare for interviews.

## 🚀 Features

- Resume PDF upload and parsing
- Resume-to-job-description matching
- Skill-gap identification
- ATS keyword analysis
- Resume improvement suggestions
- Resume rewriting
- AI mock interviews
- Technical and behavioral questions
- Answer evaluation
- Confidence and clarity feedback
- Progress tracking

## 🛠️ Technology Stack

- Python
- Streamlit
- PyMuPDF
- Ollama
- Gemma
- Pandas

## 🧠 Architecture

Resume PDF
→ Resume Parser
→ AI Engine
→ Resume Analysis

Job Description
→ AI Engine
→ Skill Gap Analysis

Interview Answer
→ AI Engine
→ Evaluation & Feedback

## 🎯 Target Users

- College students
- Fresh graduates
- Job seekers
- Career cells
- Placement training teams
